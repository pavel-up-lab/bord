# Bord

Bord — фундамент публичной анонимной борды: сервер `bord-server` и терминальный
клиент `bord`. Проект требует Go 1.27 и собирается без C toolchain.

## Разработка

```sh
make build
make test
make contract
```

Основной HTTP-контракт находится в `api/openapi.yaml`. Направление импортов:
`domain` не зависит от `app` или адаптеров, `app` зависит только от `domain`, а
адаптеры (`api`, `storage`, `media`, `events`, `client`, `tui`) направляют
зависимости внутрь. Проверка этого правила входит в `go test ./...`.

Конфигурация сервера имеет приоритет defaults → YAML → `BORD_*`; секреты
передаются только через переменные окружения или файлы секретов.

## Хранилище

`sqlc.yaml` генерирует приватный SQLite adapter из видимого SQL. Миграции имеют
неизменяемые имена `NNNNNN_name.up.sql`, встраиваются пакетом `migrations` и
применяются строго последовательно; destructive down-migrations не создаются.
Бинарник отказывается работать со схемой новее `MaxSchemaVersion`.
