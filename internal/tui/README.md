# Терминальный клиент

`bord` — Bubble Tea-клиент с клавиатурой и мышью для Linux, macOS и современного
Windows Terminal. Адрес сервера задается флагом `--server`, затем переменной
`BORD_SERVER`, затем локальным состоянием; значение по умолчанию —
`http://localhost:8080`.

## Клавиши

- `↑`/`k`, `↓`/`j` — перемещение и дозагрузка следующей страницы;
- `Tab` — смена активной панели, `Enter` — открыть, `Esc` — назад;
- `n` — новый тред, `p` — ответ, `Ctrl+S` — отправить, `Ctrl+O` — вложение;
- `r` — сверить состояние с HTTP API, `/` — поиск, `o` — вложение;
- `t` — переключить тему (`classic`, `amber`, `green`, `mono`), выбор сохраняется;
- `?` — контекстная справка, `q`/`Ctrl+C` — выход.

Левый щелчок выбирает строку и активирует панель; повторный щелчок по выбранной
доске или треду открывает ее. Колесо перемещает выбор в панели под указателем и
при достижении конца запрашивает следующую страницу. Пункты `[Тема]`,
`[Справка]`, `[← Назад]`, нижние командные зоны и кнопки редактора также можно
нажимать мышью. Все действия мыши имеют клавиатурный эквивалент.

При ширине меньше 72 колонок отображается одна активная панель. SSE является
только сигналом для повторного чтения HTTP; после `stream.reset` состояние
полностью сверяется заново. Черновик и idempotency key сохраняются в модели до
успешной отправки.

Интерфейс занимает терминал целиком и перестраивается после каждого изменения
размера. Тему можно выбрать при запуске через `--theme=classic|amber|green|mono`.

## Локальные данные и изображения

Состояние атомарно записывается в пользовательский config directory (`0600` на
Unix). Оно содержит session/delete secrets и не реализует печатающий их
`String`. Поврежденный файл изолируется с суффиксом `.corrupt-*`; потеря этого
файла означает потерю права удаления публикаций.

Вложения попадают в пользовательский cache только после проверки SHA-256.
Внешнее открытие вызывает напрямую `xdg-open`, `open` или Windows file
association adapter — имя файла никогда не передается shell. Kitty graphics
работает в режимах `--inline=auto|kitty|off`; неизвестный терминал всегда
получает текстовый fallback и явную команду внешнего открытия.
