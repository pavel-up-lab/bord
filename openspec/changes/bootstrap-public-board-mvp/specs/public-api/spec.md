# Spec Delta

## Purpose

Определяет стабильный машинный контракт между публичным сервером и клиентами, включая версионирование, ошибки, пагинацию и безопасные повторы запросов.

## ADDED Requirements

### Requirement: Версионированный HTTP API
Система SHALL публиковать MVP-операции под префиксом `/api/v1` и MUST сохранять совместимость полей в пределах версии.

#### Scenario: Запрос поддерживаемой версии
- **WHEN** клиент обращается к существующему маршруту `/api/v1`
- **THEN** сервер отвечает документом согласованной версии и указывает тип содержимого

### Requirement: Единая модель ошибок
Система SHALL возвращать ошибки в структурированном формате с машинным кодом, безопасным сообщением, идентификатором запроса и деталями допустимых полей.

#### Scenario: Ошибка валидации
- **WHEN** запрос содержит недопустимое поле
- **THEN** сервер возвращает подходящий HTTP-статус и код `validation_failed`, не включая стек или секретные данные

#### Scenario: Ограничение частоты
- **WHEN** запрос отклонен лимитом
- **THEN** сервер возвращает HTTP 429, код `rate_limited` и время допустимого повтора

### Requirement: Курсорная пагинация
Система SHALL использовать непрозрачные курсоры для изменяемых коллекций и MUST отвергать поврежденные или примененные не к той коллекции курсоры.

#### Scenario: Следующая страница
- **WHEN** клиент передает курсор, выданный для этой же коллекции
- **THEN** сервер возвращает следующую страницу без повторов элементов предыдущей страницы

### Requirement: Идемпотентное создание публикаций
Система SHALL принимать уникальный ключ идемпотентности для операций создания и возвращать исходный результат при безопасном повторе того же запроса.

#### Scenario: Повтор после потери ответа
- **WHEN** клиент повторяет идентичное создание с тем же ключом идемпотентности
- **THEN** сервер возвращает ранее созданный ресурс и не создает дубликат

#### Scenario: Повтор с другим содержимым
- **WHEN** тот же ключ используется с отличающимся содержимым
- **THEN** сервер отклоняет запрос с ошибкой `idempotency_conflict`

### Requirement: Ограничение входных данных
Система MUST отклонять тело запроса или поле, превышающее опубликованный лимит, до выполнения дорогостоящей обработки.

#### Scenario: Слишком большое тело
- **WHEN** размер тела превышает лимит маршрута
- **THEN** сервер прекращает чтение, возвращает HTTP 413 и не создает ресурс
