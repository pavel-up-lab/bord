# Spec Delta

## Purpose

Определяет наблюдаемые механизмы сдерживания флуда и спама без обязательной регистрации добросовестных участников публичной борды.

## ADDED Requirements

### Requirement: Многоуровневое ограничение частоты
Система SHALL ограничивать чтение и запись независимо по IP-индексу, подсети, анонимной сессии и типу операции с настраиваемыми порогами.

#### Scenario: Частая отправка ответов
- **WHEN** источник исчерпывает лимит публикации ответов
- **THEN** сервер временно отклоняет новые ответы с HTTP 429 и временем повтора, продолжая разрешенное чтение

### Requirement: Адаптивный proof-of-work challenge
Система SHALL иметь возможность потребовать ограниченный по времени proof-of-work challenge перед записью и MUST привязывать его к назначению и контексту запроса.

#### Scenario: Успешное решение
- **WHEN** клиент возвращает действительное неиспользованное решение до истечения срока
- **THEN** сервер разрешает одну соответствующую операцию записи при соблюдении остальных правил

#### Scenario: Повторное использование
- **WHEN** решение уже было принято ранее или относится к другой операции
- **THEN** сервер отклоняет его как недействительное

### Requirement: Жалоба на публикацию
Система SHALL позволять анонимному клиенту пожаловаться на видимый пост, указав одну из опубликованных причин без раскрытия заявителя автору.

#### Scenario: Допустимая жалоба
- **WHEN** клиент отправляет жалобу на существующий видимый пост
- **THEN** система регистрирует жалобу для модерации и возвращает подтверждение без публичного изменения поста

#### Scenario: Массовые повторные жалобы
- **WHEN** один источник многократно жалуется на тот же пост
- **THEN** система дедуплицирует или ограничивает жалобы, не увеличивая искусственно их видимый приоритет

### Requirement: Нейтральные ответы при блокировке
Система MUST не раскрывать правила обнаружения злоупотреблений, внутренние оценки риска или наличие блокировки других источников.

#### Scenario: Операция заблокированного источника
- **WHEN** заблокированный источник пытается публиковать
- **THEN** сервер возвращает безопасный публичный код отказа и идентификатор запроса без диагностических деталей
