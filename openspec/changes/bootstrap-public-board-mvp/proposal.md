# Proposal

## Why

Нужна легковесная публичная анонимная борда, которой удобно пользоваться из современного терминала на Linux, macOS и Windows, без зависимости пользовательского опыта от браузера. До начала реализации необходимо зафиксировать проверяемые границы MVP, требования безопасности публичного сервиса и разбиение работ, пригодное для параллельной разработки в Orca worktree.

## What Changes

- Создать централизованный публичный сервис досок, тредов и плоских ответов с HTTP API.
- Создать двухпанельный TUI-клиент в ретростиле Midnight Commander для современных терминалов.
- Добавить анонимные сессии без регистрации, токены удаления собственных публикаций и идентификаторы автора в пределах треда.
- Добавить изображения-вложения с безопасной серверной обработкой, inline-выводом при поддержке терминала и системным приложением как fallback.
- Добавить поток обновлений сервера через SSE и восстановление клиента после разрыва соединения.
- Добавить хранение минимально необходимых anti-abuse данных: HMAC-индекс IP, зашифрованный исходный IP, ограниченный срок хранения и структурированный аудит.
- Добавить rate limiting, proof-of-work challenge, жалобы, блокировки и административный CLI для модерации.
- Подготовить воспроизводимые сборки, конфигурацию Caddy/systemd и резервное копирование SQLite и вложений.
- Зафиксировать модульные границы и контракты так, чтобы сервер, TUI, хранилище, медиа и эксплуатационные задачи можно было реализовывать параллельно.

## Capabilities

### New Capabilities

- `board-content`: доски, каталоги, треды, ответы, ссылки на посты и жизненный цикл публикаций.
- `anonymous-sessions`: анонимная идентичность, локальные сессии, идентификаторы автора и удаление публикаций владельцем.
- `public-api`: версионированный HTTP API, единая модель ошибок, пагинация и совместимость клиентов.
- `live-updates`: подписка на события досок и тредов через SSE, переподключение и восполнение пропущенных данных.
- `media-attachments`: прием, проверка, хранение, получение и открытие изображений с безопасным fallback.
- `terminal-client`: двухпанельная клавиатурная навигация, создание публикаций и адаптация к возможностям современных терминалов.
- `abuse-controls`: лимиты, proof-of-work, жалобы и автоматические меры против флуда и спама.
- `moderation-audit`: блокировки, скрытие контента, административные операции, защищенные IP-данные и неизменяемый аудит действий.
- `service-operations`: конфигурация, health/readiness, миграции, HTTPS-развертывание, логи, очистка данных и резервное копирование.

### Modified Capabilities

Нет — проект создается с нуля.

## Impact

- Новый Go-монорепозиторий с бинарниками `bord` и `bord-server`, общими API-моделями и внутренними пакетами.
- Новая SQLite-схема в WAL-режиме, файловое хранилище вложений и миграции с возможностью последующего перехода на PostgreSQL.
- Новые зависимости TUI, HTTP-маршрутизации, SSE, конфигурации, миграций и безопасной обработки изображений.
- Новые публичные HTTP/SSE-контракты и локальный формат конфигурации клиента.
- Эксплуатационные артефакты для Caddy, systemd, ротации логов, резервного копирования и сроков хранения персональных данных.
- Основная поддерживаемая клиентская среда: Linux, macOS и современный Windows Terminal; старый `cmd.exe` не входит в область поддержки.
