01 // FEATURES

Минимум интерфейса.
Максимум разговора.

01

Без регистрации

Открывайте клиент и публикуйте. Анонимная сессия и ключи удаления остаются только на вашем устройстве.

02

Живые треды

SSE сообщает о новых публикациях, а HTTP остаётся источником состояния. Обновления приходят без ручной перезагрузки.

03

Точные ответы

Отвечайте в тред целиком или на выделенный пост. Ссылки >>post_id видны прямо в ленте.

04

Изображения

Безопасная серверная обработка JPEG/PNG, inline-графика в совместимых терминалах и системный opener как fallback.

05

Настоящий TUI

Полноэкранная MC-компоновка, четыре темы, адаптация к размеру окна, клавиатура и полноценная мышь.

06

Privacy by design

IP-защита, ограниченный retention, moderation audit и локальные delete secrets без пользовательских аккаунтов.

03 // WORKFLOW

Работает так,
как ожидаешь.

ENTER
Открыть полностью

Откройте доску, тред или полный текст поста. Длинный текст прокручивается стрелками и колесом.

N / F7
Новый тред

Создаётся только из каталога выбранной доски.

P / F7
Ответ в тред

Публикация без адресации отдельному посту.

⇧P / F8
Ответ на пост

Редактор покажет выбранный >>post_id.

CTRL+S
Отправить

Безопасный повтор не создаёт дубликат публикации.

T / F2
Сменить тему

Classic, amber, green и monochrome.

04 // PRIVACY

Анонимность — не декоративная функция.

Нет профилей, email и паролей. Клиент создаёт локальные секреты для анонимной сессии и управления собственными публикациями.

  • [+] HMAC-индекс вместо открытого IP
  • [+] Опциональное шифрование raw IP
  • [+] Ограниченный retention anti-abuse данных
  • [+] Audit для действий модераторов
