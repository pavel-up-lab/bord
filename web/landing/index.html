01 // FEATURES

Минимум интерфейса.
Максимум разговора.

01

Без регистрации

Открывайте клиент и публикуйте. Анонимная сессия и ключи удаления остаются только на вашем устройстве.

02

Живые треды

SSE сообщает о новых публикациях, а HTTP остаётся источником состояния. Обновления приходят без ручной перезагрузки.

03

Точные ответы

Отвечайте в тред целиком или на выделенный пост. Ссылки >>post_id видны прямо в ленте.

04

Изображения

Безопасная серверная обработка JPEG/PNG, inline-графика в совместимых терминалах и системный opener как fallback.

05

Настоящий TUI

Полноэкранная MC-компоновка, четыре темы, адаптация к размеру окна, клавиатура и полноценная мышь.

06

Privacy by design

IP-защита, ограниченный retention, moderation audit и локальные delete secrets без пользовательских аккаунтов.

04 // IMAGES

Картинки
в терминале.

В Bord откройте Настройки → Изображения. Нативный режим использует Kitty graphics protocol, ANSI работает без графического протокола, а w3m требует отдельной установки.

Совместимость: Bord передаёт PNG через Kitty graphics protocol. Его понимают Kitty, актуальный iTerm2 и WezTerm. Windows Terminal этот протокол не поддерживает — используйте ANSI или WezTerm.

LINUX // KITTY

Kitty или WezTerm

  1. Установите Kitty пакетным менеджером.
  2. Запустите терминал kitty.
  3. Откройте Bord — режим «Нативный» определит Kitty автоматически.
LINUX.SH
sudo apt install kitty
kitty
bord --inline kitty

Для Fedora используйте sudo dnf install kitty, для Arch — sudo pacman -S kitty.

macOS // iTerm2

Работает нативно

Актуальный iTerm2 поддерживает Kitty graphics protocol. Обновите iTerm2 и запустите Bord с нативным протоколом. Отдельный Kitty устанавливать не нужно.

MACOS.SH
brew upgrade --cask iterm2
bord --inline kitty

Следующая сборка распознает iTerm2 автоматически. Если изображение не появилось, проверьте без tmux; ANSI остаётся универсальным fallback.

WINDOWS // POWERSHELL

PowerShell внутри WezTerm

PowerShell — это shell, а картинки рисует терминал. Windows Terminal пока не поддерживает используемый Bord протокол: там выберите ANSI. Для нативного качества запустите PowerShell внутри WezTerm.

POWERSHELL
winget install --id wez.wezterm -e
wezterm start -- pwsh.exe -NoLogo
# В открывшемся WezTerm:
bord.exe --inline kitty

Следующая сборка распознает WezTerm автоматически. В Windows Terminal используйте S / F6 → Изображения → ANSI.
